# ⚡️ Кайрос & 🌸 Хрона — Умная экосистема Telegram-ботов

Экосистема из двух взаимосвязанных ботов для вайбкодинга, управления игровыми проектами, бизнес-консалтинга и академического расписания.

## 👥 Персонажи

### 1. ⚡️ Кайрос (Kairos) — Бизнес & Вайбкодинг-партнёр
- **Профиль:** Парень 25–30 лет, инди-разработчик, предприниматель. Общается на «ты», с драйвом и знанием дела.
- **Специализации:**
  - 🏛 **Steam: Мифология & Хроники Акаши** — лор, проработка богов (Греция, Рим, Славяне, Скандинавы), квесты, удержание, оформление в Steam.
  - 🕹 **Яндекс.Игры** — быстрые концепты для мужа, механики гиперказуальных/мидкорных игр, D1/D7 retention, реклама.
  - 💡 **Бизнес-консалтинг** — разбор сторонних идей, юнит-экономика, MVP за выходные.
  - 🚀 **Взятие идей в работу** — превращение идеи в полноценный проект с собственным режимом и передачей дедлайна Хроне.

### 2. 🌸 Хрона (Chrona) — Расписание & Семейный продюсер
- **Профиль:** Девушка 25 лет, хранительница времени и баланса. Структурная, заботливая, организованная.
- **Специализации:**
  - 🎓 **Академическое расписание** (учеба, зачёты, пары, сессия).
  - 💼 **Бизнес и геймдев-спринты** (дедлайны по Steam, релизам Яндекс.Игр).
  - ⚖️ **Семейный баланс** (нагрузка Полины + мужа, защита от выгорания).
  - 🔗 **Приём сигналов от Кайроса** (автоматическое бронирование слотов при старте новых проектов).

## 🛠 Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните параметры:
- `KAIROS_BOT_TOKEN` — токен Кайроса из [@BotFather](https://t.me/BotFather)
- `CHRONA_BOT_TOKEN` — токен Хроны из [@BotFather](https://t.me/BotFather)
- `GEMINI_API_KEY` — ключ к Gemini API ([Google AI Studio](https://aistudio.google.com/))

### 3. Запуск обоих ботов одной командой
```bash
python run_ecosystem.py
```
Либо по отдельности:
```bash
python kairos_bot.py
python chrona_bot.py
```

## 🔄 Как работает мост синхронизации
1. Когда в диалоге с Кайросом утверждается идея: нажимаете кнопку **«🚀 Взять эту идею в работу»** или команду `/take Название проекта`.
2. Кайрос сохраняет проект в общую базу данных и отправляет сигнал Хроне.
3. Хрона бронирует дедлайны и спринты в расписании.
4. Кайрос перед планированием больших задач опрашивает Хрону: если на неделе завал по учебе, Кайрос рекомендует сократить скоуп задач.
